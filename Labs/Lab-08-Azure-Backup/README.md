# Lab 08 - Azure Backup

## Objective

Learn how Azure Backup uses Recovery Services Vaults to protect workloads and enable recovery of data and systems.

## Tasks Completed

- Explored a Recovery Services Vault
- Reviewed Backup Policies
- Reviewed Backup Infrastructure
- Reviewed Backup Jobs
- Reviewed Backup Items

## What I Learned

Azure Backup uses Recovery Services Vaults to store and manage backup data.

Backup Policies determine how frequently backups occur and how long they are retained.

Backup Jobs are used to monitor backup and restore operations.

Recovery Services Vaults play an important role in business continuity and disaster recovery.

## Real World Scenario

If a production server became unavailable due to hardware failure, malware or accidental deletion, Azure Backup could be used to restore the server and minimise downtime.

## Lessons Learned

Backups are a critical component of any disaster recovery strategy.

Regular testing of backup and recovery processes is just as important as creating backups.
