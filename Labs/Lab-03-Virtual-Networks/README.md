# Lab 03 - Azure Virtual Networks

## Objective

Learn how Azure Virtual Networks (VNets) and Subnets work.

## Tasks Completed

- Created a Virtual Network
- Configured Address Space
- Created a Server Subnet
- Deployed the Virtual Network

## Configuration

VNET Name: VNET-AZ104-LAB

Address Space:
10.0.0.0/16

Subnet:
Servers

Subnet Range:
10.0.1.0/24

## What I Learned

A Virtual Network is a private network within Azure.

Subnets are used to segment resources into smaller network boundaries for security and management.

Network segmentation can help reduce lateral movement if a device or user account becomes compromised.
