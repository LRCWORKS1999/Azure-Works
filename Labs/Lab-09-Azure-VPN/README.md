# Lab 09 - Azure VPN

## Objective

Learn how Azure VPNs provide secure connectivity between users, office networks and Azure resources.

## Tasks Completed

- Explored Azure Virtual Network Gateway
- Reviewed VPN Gateway deployment options
- Investigated Point-to-Site (P2S) VPNs
- Investigated Site-to-Site (S2S) VPNs
- Reviewed Azure hybrid networking concepts

## What I Learned

Azure VPNs provide secure encrypted communication between Azure and external networks.

There are two common Azure VPN types:

### Point-to-Site (P2S)

Used when an individual user or device needs secure access to Azure resources.

Example:

- IT Administrator working remotely
- Laptop connecting to Azure resources

### Site-to-Site (S2S)

Used when an entire office or on-premises network needs permanent connectivity to Azure.

Example:

- Office Firewall
- Azure VPN Gateway

## Real World Scenario

Crystal Electronics


## Lessons Learned

Point-to-Site VPNs are designed for individual users and devices.

Site-to-Site VPNs connect entire networks together and are commonly used for hybrid cloud deployments.

A Site-to-Site VPN would be the preferred solution for connecting an office network to Azure resources on a permanent basis.
