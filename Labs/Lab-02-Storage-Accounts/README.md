# Lab 01 - Azure Storage Accounts

## Objective

Learn how Azure Storage Accounts and Blob Containers work.

## Tasks Completed

- Created a Storage Account
- Created a Blob Container
- Uploaded a text file

## What I Learned

Azure Blob Storage uses containers to store files and data in the cloud.
A Storage Account acts as the parent resource that contains storage services.
