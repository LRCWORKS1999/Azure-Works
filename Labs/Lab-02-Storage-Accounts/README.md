# Lab 02 - Azure Storage Accounts

## Objective

Learn how Azure Storage Accounts work.

## Tasks Completed

- Created a Resource Group
- Created a Storage Account
- Created a Blob Container
- Uploaded a file
- Created an Azure File Share
- Uploaded a file

## What I Learned

Azure Storage Accounts provide multiple storage services.

Blob Containers are used for object storage.

Azure File Shares provide SMB based file shares that can be used as an alternative to traditional file servers.
