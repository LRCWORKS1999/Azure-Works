## Real World Experience

I led the rollout of Microsoft Authenticator MFA across the organisation.

The project included:

- User communication and onboarding
- Microsoft Authenticator enrollment
- Enforcement of MFA registration
- Company-wide password reset campaign
- Security awareness guidance
- Improved authentication security posture

## Outcome

All users were enrolled into MFA and stronger password requirements were enforced.

This significantly reduced the risk of account compromise through password theft and phishing attacks.


## What I Learned

MFA adds a second factor of authentication beyond a username and password.

Microsoft Authenticator provides a secure authentication method through push notifications and number matching.

Administrators can control which authentication methods are available to users through Authentication Method Policies.

MFA significantly reduces the risk of account compromise caused by password theft or phishing.
