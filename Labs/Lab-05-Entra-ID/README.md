# Lab 05 - Microsoft Entra ID

## Objective

Learn how identities, users and groups are managed in Microsoft Entra ID.

## Tasks Completed

- Explored Microsoft Entra ID
- Reviewed Users
- Reviewed Groups
- Reviewed Roles and Administrators
- Created Test Users (if permitted)
- Created Security Groups (if permitted)

## What I Learned

Microsoft Entra ID is Microsoft's cloud identity platform.

Authentication verifies identity.

Authorisation determines permissions.

Groups simplify permission management.

Permissions should be assigned to groups rather than individual users wherever possible.
This simplifies administration, improves security and makes access reviews easier.
