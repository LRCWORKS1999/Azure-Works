# Lab 05 - Microsoft Entra ID

## Objective

Understand how Microsoft Entra ID manages cloud identities, groups and administrative roles.

## Tasks Completed

- Explored Microsoft Entra ID
- Reviewed Users
- Reviewed Groups
- Reviewed Roles and Administrators

## Key Concepts Learned

### Authentication

Authentication verifies a user's identity using credentials such as usernames, passwords and MFA.

### Authorization

Authorization determines what resources a user is permitted to access.

### Users

Users represent individual identities within Entra ID.

### Groups

Groups simplify permission management by assigning permissions to groups rather than individual users.

### Administrative Roles

Administrative roles provide delegated permissions for specific tasks.

Examples include:

- Global Administrator
- User Administrator
- Groups Administrator

## Lessons Learned

- Permissions should be assigned through groups wherever possible.
- The principle of least privilege should be followed.
- User Administrator is more appropriate than Global Administrator for managing user accounts.
