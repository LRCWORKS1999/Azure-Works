# Lab 04 - Azure Virtual Machines

## Objective

Deploy a Windows Server Virtual Machine in Azure.

## Tasks Completed

- Created Azure Virtual Machine
- Configured Administrator Account
- Created Public IP Address
- Created Network Interface
- Created Network Security Group
- Connected VM to a Virtual Network

## VM Details

Name: VM-SRV01

Operating System:
Windows Server 2022 Datacenter

## Problems Encountered

The VM could not initially be deployed due to region and availability restrictions.

## Resolution

Changed the availability option to:

No infrastructure redundancy required

Deployed the VM into South Africa North using a compatible VM size.

## What I Learned

Azure Virtual Machines are deployed into Virtual Networks and Subnets.

Azure automatically creates supporting resources such as:

- Network Interfaces
- Public IP Addresses
- Network Security Groups
